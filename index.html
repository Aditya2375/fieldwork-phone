LEGACY EMAIL-RELAY PROJECT

This legacy Jarvis Phone design was a personal Android email-relay app. Its intended function was to send a message created on the phone as an email from the operator's Google account to one chosen recipient.

The design used the Gmail API's gmail.send scope for sending, not inbox access. This archived description is not a current APK security assessment.

The legacy design described no app-operated server. Email delivery still involves Google Gmail and the chosen recipient.
